# keri-priv-analysis-suite

Measures what a KERI/ACDC deployment lets each adversary join about a citizen, on any implementation: for each party (colluding verifiers, a hacker or insider who obtains stored data, a government office that compels disclosure, a network observer), what it can join, how many identifying bits that yields per citizen, how certain the join is and how complete. It never claims that something cannot be linked.

**Status: incubating.** The suite is developed at [Bakobo](https://bakobo.com) with the intention of contributing it to the KERI Foundation.
